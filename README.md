# Graphics-and-visualization

A collection of projects and laboratory assignments for the Graphics and Visualization course. This repository contains coursework and personal projects created to deepen my understanding of 3D rendering, ray tracing algorithms, custom shaders, and 3D scene modeling.

## 📁 Projects

* **blender:** 3D scene modeling, procedural material setups, and automated rendering workflow experiments.
* **raytracer:** Custom offline ray tracer built in `C++` supporting ray-object intersections, reflections, refractions, and lighting models.
* **unity:** Interactive real-time 3D environments featuring custom `HLSL` / ShaderLab shaders and rendering pipelines.

## 🛠 Technologies

* `C++`
* `HLSL` / ShaderLab
* Unity Engine
* Blender
* Vector Math & Matrix Transformations

## 💡 What I learned

* Implementing core ray tracing algorithms, ray-mesh intersections, and light transport models from scratch.
* Writing custom vertex and pixel shaders in `HLSL` for real-time graphics and visual effects.
* Understanding 3D projection matrices, camera spaces, and coordinate system transformations.
* Configuring materials, specular/diffuse lighting models, and shadow calculations.
* Balancing visual fidelity with performance in both real-time and offline rendering pipelines.
